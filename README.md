# AdaptiveAI Quiz Engine

An AI-powered adaptive learning system that combines Reinforcement Learning and Google's Gemini API to personalize quiz experiences for students.

## Problem

Most online quizzes provide the same difficulty level to every learner. This leads to boredom for advanced students and frustration for beginners.

## Solution

AdaptiveAI uses Reinforcement Learning to dynamically adjust quiz difficulty based on performance while generating fresh questions using Gemini.

## Features

* Reinforcement Learning based difficulty adaptation
* Dynamic MCQ generation using Gemini API
* Multi-subject support
* Interactive quiz sessions
* Adaptive learning states
* Performance tracking
* Difficulty evolution visualization

## Tech Stack

* Python
* NumPy
* Matplotlib
* Q-Learning
* Google Gemini API
* Colorama

## Workflow

Student → RL Agent → Difficulty Selection → Gemini Question Generation → Student Response → Difficulty Adaptation
